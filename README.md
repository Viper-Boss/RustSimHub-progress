# RustSimHub 开发进度看板

公开网址：https://viper-boss.github.io/RustSimHub-progress/

本仓库只发布开发进度快照、任务清单和看板页面源码。固件业务代码、设备数据、密钥、备份和原始日志保留在私有项目，不在本仓库。

- `index.html`：可离线打开的完整交互看板，五人并排代码占比，点击详情查看任务。
- `progress.json`：页面展示的公开任务及统计快照。
- `remaining.md`：完整剩余动作清单。
- `src/`、`build.py`：看板页面对应源码及独立重建脚本，不包含固件实现。
- `publication.json`：本次发布来源和页面摘要。

原固件里程碑估算81.5%；完整剩余行动台账20/169、加权10.6%；接回D包20/26为离线交付。三者范围不同，均不等于全需求已经验收。代码量按页面列明的固定主线提交统计，未合并PR不冒记进主线行数，也不等于权属比例。

这是来源PR #58的看板快照，页面交付不等于该PR的固件实现已合入。页面内部分证据链接指向私有项目，只有获授权成员能访问；看板本身无需登录。

重建页面：`python build.py --check` 核对当前页面，`python build.py` 重新生成。完整任务验收仍由私有项目维护流程执行；此公开脚本只负责页面重建，不接受任务或更改完成状态。

更新时先在私有项目校验全部台账/归属和页面，再只同步本仓库这些明确允许的文件，不镜像固件仓库。界面代码沿用AGPL-3.0-only，见LICENSE。
