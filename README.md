# RustSimHub 开发进度看板

公开网址：https://viper-boss.github.io/RustSimHub-progress/

本仓库只发布开发进度快照、任务清单和看板页面源码。固件业务代码、设备数据、密钥、备份和原始日志保留在私有项目，不在本仓库。

- `index.html`：可离线打开的完整交互看板，五人并排PR提交量占比，点击详情查看任务。
- `progress.json`：页面展示的公开任务及统计快照。
- `remaining.md`：完整剩余动作清单。
- `src/`、`build.py`：看板页面对应源码及独立重建脚本，不包含固件实现。
- `publication.json`：本次发布来源和文件摘要。

本截面原固件里程碑估算81.5%，完整剩余行动台账20/169项完成。原范围与新增扩展、源码交付/设备验收分别记录，不能混算。人员提交工作量按已收录的PR编号去重统计，未合并、已合并和已关闭未合并均计入，每个PR计1次。占比不代表工时、代码行数或验收完成率。当前PR数据时间保留在页面，最新远程同步尚未完成。

界面由PR58交付；本次数据/页面快照来源：https://github.com/Viper-Boss/RustSimHub/pull/66，固定源码提交 `5d3c9668f1465de22b583a084d8f21048035517a`。看板发布不代表该私有产品PR已经合入main或部署设备。页面内部分证据链接指向私有项目，只有获授权成员能访问；看板本身无需登录。

重建页面：`python build.py --check` 核对当前页面，`python build.py` 重新生成。完整任务验收由私有项目维护流程执行，此公开脚本只负责页面重建，不接受任务或改变完成状态。

更新时先在私有项目校验全部台账/归属和页面，再只同步本仓库这13个白名单文件，不镜像固件仓库。界面代码沿用AGPL-3.0-only，见LICENSE。
